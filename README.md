# وب‌سایت و لندینگ رسمی گروه دارینه (`darineh.com`)

این مخزن شامل صفحه لندینگ رسمی، دارایی‌های گرافیکی و اسکریپت ساخت فایل‌های ایستای وب‌سایت رسمی **گروه دارینه** ([darineh.com](https://darineh.com)) است.

---

## ▌ ساختار مخزن

* **`Darineh Landing.dc.html`**: فایل سورس طراحی Claude Design (قالب اصلی لندینگ پیج).
* **`build.py`**: اسکریپت پایتون جهت تبدیل و بیلد سورس طراحی به خروجی استاندارد وب در مسیر `dist/`.
* **`dist/`**: خروجی کامپایل‌شده و آماده برای سرو مستقیم روی وب‌سرور (شامل `index.html`، فونت‌ها، اسست‌ها و `robots.txt`).
* **`assets/`**: تصاویر، آیکون‌ها و متادیتاهای استفاده‌شده در صفحهٔ اصلی.
* **`fonts/`**: قلم‌های وزیرمتن (Vazirmatn) و لاله‌زار (Lalezar).
* **`branding/`**: لوگوهای رسمی برداری (SVG) و وضوح بالای نشان تجاری دارینه و محصولات زیرمجموعه.
* **`deploy/`**: راهنما و پیکربندی استقرار بر روی وب‌سرور Caddy.

---

## ▌ نیازمندی‌ها و نحوهٔ بیلد

برای تولید مجدد خروجی، تنها به پایتون ۳ نیاز است:

```bash
# بیلد فایل‌های ایستا در پوشه dist
python3 build.py
```

خروجی در مسیر `dist/index.html` به‌همراه دارایی‌ها ساخته می‌شود.

---

## ▌ استقرار (Deployment)

وب‌سایت اصلی بر روی سرور دارینه و با وب‌سرور [Caddy](deploy/Caddyfile) سرو می‌شود:

```bash
# کپی خروجی بیلد به مسیر سرور
sudo mkdir -p /srv/darineh-landing
sudo cp -r dist/* /srv/darineh-landing/
```

تنظیمات Caddyfile در مسیر `deploy/Caddyfile` قرار دارد و با بارگذاری مجدد Caddy فعال می‌شود.
